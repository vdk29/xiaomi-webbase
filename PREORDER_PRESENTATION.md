# Предзаказ: Xiaomi 18 Pro и Xiaomi 18 Pro Max

Данные проверены 6 ноября 2026 года. Раздел `index.html?section=preorder` использует существующий доступ сотрудников.

## Версия и источники

По запросу владельца восстановлены полные характеристики и цвета **китайских версий** двух моделей:

- https://www.mi.com/prod/xiaomi-18-pro и `/specs`
- https://www.mi.com/prod/xiaomi-18-pro-max и `/specs`

Регион указан в презентации, карточке, характеристиках, источниках и копируемой конфигурации. Предварительные параметры европейских поставок убраны. Это не спецификации Global: языки, сервисы и условия конкретной поставки уточняются отдельно.

У каждой модели сохранены пять цветов китайской версии (обычный Red из прайса 1С добавлен отдельно, см. раздел от 07.11.2026): чёрный, белый, ледяной персик, звёздный синий и прозрачный красный Special Edition. Прозрачное исполнение ограничено 16 ГБ / 1 ТБ; при смене цвета память проверяется повторно. У всех цветов свои локальные фотографии производителя. Источники и хеши медиа — `assets/preorder/manifest.json`. Складские фото не менялись.

Исключённые Fold, 17 Max, 17T, 17T Pro и блок обычного Xiaomi 18 не возвращены. Сравнительной таблицы нет.

## Оформление и мобильная версия

Тёплый оранжевый, светлые сиреневые и бирюзовые акценты; контрастный тёмный текст, цветные карточки ключевых параметров и разделов. Семь открытых групп характеристик (51 параметр) с быстрыми ссылками. На телефоне — одна колонка, кнопки цвета с названиями, крупные зоны нажатия, память сеткой 2×2; горизонтальной прокрутки характеристик нет. Фото товара отображаются целиком, без обрезки. Изображения примеров съёмки также отображаются целиком.

Медиа, JS и CSS загружаются только при открытии вкладки; видео — по нажатию. Иллюстрация заднего экрана подписана как схема. Цена и наличие не выдумываются, копирование не оформляет заказ. Каталог не загружается при прямом входе в презентацию. Товары, остатки, сотрудники и схема Supabase не менялись.

## Проверки

`npm run check`, `npm test`, `node scripts/verify-preorder-ui.cjs` (сервер 4173; поддерживаются `CHROMIUM_PATH`, `WEBBASE_TEST_URL`). Браузер проверяет 1440, 768, 430, 390 и 320 px, все десять фотографий, подписи цветов, специальные конфигурации, сохранение после обновления, семь открытых групп, размер шрифта и кнопок, отсутствие горизонтального переполнения, видео и переходы. Чтение авторизации/каталога подменено в тесте; записей в рабочую базу нет.

## Цены из 1С и экран Pro Max — 07.11.2026

Цены переписаны из **двух фотографий 1С, присланных пользователем**, в `js/preorder-prices.js`. Это отдельный прайс презентации; рабочие остатки и товары Supabase не меняются. Автоматического обновления цен из 1С нет.

| Модель | ОЗУ / память | Цена | Цвета в исходных строках |
| --- | --- | --- | --- |
| Xiaomi 18 Pro | 12 / 256 ГБ | 139 990 ₽ | Black, White, Blue, Red |
| Xiaomi 18 Pro | 12 / 512 ГБ | 149 990 ₽ | Black, White, Blue, Red |
| Xiaomi 18 Pro Max | 12 / 256 ГБ | 159 990 ₽ | Black, White, Blue, Red |
| Xiaomi 18 Pro Max | 12 / 512 ГБ | 169 990 ₽ | Black, White, Blue, Red |

Проверены все 16 сочетаний. Цена ищется строго по модели, памяти и цвету. Для розового, прозрачного Special Edition и вариантов с 16 ГБ ОЗУ цены не предоставлены: интерфейс и скопированный запрос показывают, что цену нужно уточнить. Red — отдельное непрозрачное исполнение из 1С; фотография прозрачной версии не используется вместо него. Два каталожных изображения Red получены из https://androidtreasure.com/xiaomi-18-pro-max-europe-listing-red-color/ (публикация рендеров европейского каталога). Наименования 1С не определяют регион поставки. Китайские характеристики сохранены по ранее принятому запросу владельца; они не являются обещанием региональной комплектации позиции из прайса. В списке цветов китайской спецификации retail-only Red не перечисляется.

`js/rear-display.js` заменяет нарисованный корпус реальным изображением **18 Pro Max** из официальной презентации Xiaomi. Исходное изображение сохранено целиком, оптимизировано по формату; CSS показывает крупный план, SVG-маска сохраняет видимость физических камер. Содержимое экрана нарисовано для демонстрации и подписано соответствующим образом. Это не запись штатного интерфейса телефона.

Сценарии: время/дата, GIF, фотообои, музыка (без звука), уведомление, рабочий фокус-таймер, предварительный просмотр камеры и AI-карточка. Часы показывают время устройства посетителя; погода, уведомления, музыка, AI-карточка и снимок камеры — условные примеры. Таймер можно запустить/остановить/сбросить. При уходе из вкладки таймеры и анимация приостанавливаются; при возвращении контроллер возобновляется без новых подписок. Видео по-прежнему запускается только вручную.

Источники функций и настройки:
