## Применение и проверка

`supabase/seed_product_descriptions_20261024.sql` — повторяемое заполнение только
пустых описаний. Перед записью сверяются UUID, полный SKU и название каждой
карточки. Собственные описания и существующие характеристики не перезаписываются.
Это контентное заполнение существующей базы, без миграции схемы.

После применения сверены контрольные суммы остальных полей товаров, остатков,
метаданных фото, объектов Storage и сотрудников: изменений нет. Существующие
характеристики сверены отдельно: изменений нет. Проверка сохранения описания
при импорте: `tests/description-reimport.sql`, с откатом всех тестовых записей.
