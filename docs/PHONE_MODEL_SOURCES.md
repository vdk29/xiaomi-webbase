# Готовая 3D-модель Xiaomi 18 Pro / Pro Max

## Текущий вариант на сайте — независимое моделирование, 18.11.2026

По следующему заданию пользователя созданы собственные GLB-модели Pro и Pro Max на основе официальных размеров и изображений Xiaomi. Они заменяют прежний корпус в браузере и поддерживают действующие интерактивные экраны и цвета. Исходники и источники: [assets/preorder/models/README.md](../assets/preorder/models/README.md). Это самостоятельная реконструкция; файл TurboSquid не использован. Результат и проверки описаны в [PREORDER_PRESENTATION.md](../PREORDER_PRESENTATION.md).

Геометрия, текстуры, UV и состав конкретного glTF-архива фактически не проверены: файл не получен. Обычный запрос к странице возвращает HTTP 403 / DataDome. Ограничения не обходились, файлы из превью не извлекались. Цена и возможность бесплатного оформления в текущем сеансе не подтверждены; «Free file format Conversions» означает бесплатную конвертацию формата, а не бесплатную модель.

### Применимость лицензии

[TurboSquid Licensing](https://www.turbosquid.com/licensing), разделы Editorial Uses и 7(b), ограничивают коммерческое использование Editorial-моделей и передачу открытых файлов через WebGL. Для WebBase нужны подтверждение прав на коммерческую демонстрацию Xiaomi и отдельное согласование доставки GLB через Three.js. Покупка сама по себе этих вопросов не решает. [Editorial FAQ](https://www.turbosquid.com/help/en/articles/9937424-editorial-use-information) допускает использование официальным лицензиатом с соответствующими правами.

Текущие код и сайт публичны на GitHub / GitHub Pages; вход сотрудника не защищает загружаемый браузером GLB от извлечения. Исходный купленный архив не следует добавлять в публичный репозиторий. Готовый [запрос в поддержку](TURBOSQUID_2654598_REQUEST.md) описывает именно нашу архитектуру; он подготовлен, но никому не отправлен.

Его веб-размещение тоже требует проверки условий. Модели других поколений и фотографии под видом 3D не используются.

### Что нужно предоставить для интеграции выбранного варианта

1. Архив **TurboSquid 2654598 / Xiaomi 18 Pro Black / MeshMarket**: предпочтительно glTF 2.0 — `.glb` либо `.gltf` + `.bin` + все текстуры. Альтернатива — FBX с текстурами. Исходный `.blend` полезен для материалов, но не заменяет обменный формат: сейчас в окружении Blender 4.3.2, а автор указывает 5.2.
2. Условия полученной лицензии и подтверждение допустимости коммерческой демонстрации / доставки оптимизированного GLB браузеру. Платёжные реквизиты и пароли не нужны.

Для iPhone нужен базовый уровень детализации Subdivision 0; уровни 1 и 2 заметно тяжелее. Перед публикацией необходимо проверить импорт, масштаб Pro 151,8 × 72 мм, материалы, четыре Global-цвета, отдельно определить границы/UV заднего экрана Pro 912 × 596 и совместить его с существующими интерактивными сценариями. Текущие координаты в `js/rear-display-geometry.js` относятся к Pro Max 976 × 596 и не должны переноситься без калибровки.

Оптимизация после получения файла: удалить неиспользуемые объекты сцены, подготовить совместимые PBR-материалы, сжать геометрию и текстуры, проверить качество и размер GLB на мобильном устройстве. Конкретные параметры и результат пока не заявляются: исходник не доступен.

**Результат первоначальной проверки TurboSquid (до независимого моделирования):** замена тогда не выполнена; новый GLB не скачан и не опубликован. Исполняемый код, существующая 3D-модель, функции предзаказа, цены, каталог и Supabase не менялись. Обновлены только этот документ и текст обращения в поддержку. Тесты приложения для изменения документации не запускались.

## Что реально сделано

Открыты страницы, сверены название устройства, цена, форматы и пометки лицензии. Модели не куплены, платные файлы не скачаны, превью не извлекались в обход скачивания. Поэтому готовая сторонняя геометрия в сайт не встроена; текущий корпус не выдаётся за скачанную модель.

Для замены нужен приобретённый файл (предпочтительно GLB/glTF; OBJ/FBX тоже подходят) вместе с текстурами и условиями использования в WebBase. До получения файла нельзя проверить UV, точность геометрии, разделение переднего/заднего стекла и окончательный размер мобильной версии.

После получения модель необходимо оптимизировать и совместить с живыми DOM-дисплеями. Исходный тяжёлый архив не должен загружаться на iPhone. Текущая архитектура Three.js уже обеспечивает общий ракурс корпуса и обоих интерактивных экранов.

[Условия CGTrader](https://www.cgtrader.com/pages/terms-and-conditions) различают встроенный продукт и распространение исходного файла. [Editorial-ограничения TurboSquid](https://www.turbosquid.com/licensing) отдельно запрещают коммерческое/промоиспользование без соответствующих прав.
