# Помощь продавцу смартфона

В карточках категории «Смартфоны» вместо видимого описания выводится подсказка для консультации. Остальные категории показывают прежнее описание. Исходные описания, характеристики, фотографии и остатки в Supabase не меняются; форма редактирования описания сохраняется.

Сценарий: три вопроса → рекомендация под задачу → факт / выгода / готовая фраза / демонстрация → ответы на возражения → проверка поставки → завершение консультации. На телефоне — одна колонка, ссылки на темы и раскрывающиеся дополнительные разделы. Все сведения локальны: новых API-запросов и загрузок со сторонних сайтов при открытии товара нет.

На 07.11.2026 проверены все 62 активных смартфона, восемь семейств. Факты в `js/seller-help-data.js`, сборка и экранирование в `js/seller-help.js`. Название семейства должно совпадать полностью до варианта памяти: нельзя наследовать данные между REDMI/Xiaomi/POCO, Note/Pro/Max/Ultra, 4G/5G. Неизвестная новая модель получает вопросы и подсказку по своей памяти, без вымышленных характеристик. Подробный профиль для нового семейства добавляется после проверки источников.

Память — из названия выбранной номенклатуры, затем из поля `memory`; не из общей таблицы характеристик модели. Не нужно обновлять все цвета и объёмы по отдельности. Повторная выгрузка 1С не стирает помощь: она формируется при показе карточки.

## Расхождения и ограничения

В старых карточках есть различия с актуальными источниками: например, у POCO F9 Pro диагональ из магазина 6,59″ против официальных 6,9″; у REDMI 17 встречается Adreno 610 вместе с Helio. Подсказка использует проверенный профиль, старые характеристики не переписывает. Предупреждение о сверке поставки доступно отдельно.

У Note 17 Pro Max 5G разные официальные рынки действительно указывают 9210/10000 мА·ч. Подсказка сохраняет известную ёмкость из карточки с оговоркой о проверке региона; если значения нет или оно неизвестно, показывает оба варианта, не выбирая регион по цвету. Нельзя считать нашу карточку доказательством рынка поставки.

Не обещаются дни автономности, время зарядки, FPS, водонепроницаемость, доступность eSIM/NFC/сервисов или наличие адаптера без проверки. Гц не приравниваются к FPS, виртуальная ОЗУ — к физической, мегапиксели — к качеству всех фотографий.
